# Day 6: Working with Files & Directories

## What I Learned

Today I learned how to create, copy, move, rename, and remove files and directories in Linux.

## Commands Practiced

### 1. Creating Files and Directories

- `mkdir` - Creates a directory.
- `mkdir -p` - Creates parent directories when needed.
- `touch` - Creates an empty file if it does not exist.

### 2. Copying Files and Directories

- `cp` - Copies a file while keeping the original.
- `cp -r` - Copies a directory and its contents.

### 3. Moving and Renaming

- `mv` - Moves files or directories to another location.
- `mv` can also rename files and directories.

### 4. Removing Files and Directories

- `rm` - Removes a file.
- `rmdir` - Removes an empty directory.
- `rm -r` - Removes a directory and its contents.

Practiced the following tasks:

- Copied a file into another directory using `cp`.
- Copied directories using `cp -r`.
- Moved files using `mv`.
- Renamed files using `mv`.
- Renamed directories using `mv`.
- Removed files using `rm`.
- Removed empty directories using `rmdir`.

## Important Concepts

- `cp` creates a copy and preserves the original file.
- `mv` moves a file or directory and can also rename it.
- `cp -r` copies directories recursively.
- `rmdir` only removes empty directories.
- `rm -r` removes directories and their contents.
- Removal commands should be used carefully because deleted files may not be recoverable.

## Remember

- `mkdir` → Create a directory.
- `touch` → Create an empty file.
- `cp` → Copy a file.
- `cp -r` → Copy a directory and its contents.
- `mv` → Move or rename files and directories.
- `rm` → Remove a file.
- `rmdir` → Remove an empty directory.
- `rm -r` → Remove a directory and its contents.
