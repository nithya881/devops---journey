# Day 5: Navigating Directories

## What I Learned

Today I learned how to navigate through directories in Linux using absolute paths, relative paths and navigation commands.

## Commands Practiced

- `pwd` = Print the current working directory
- `ls` = List directory contents
- `cd` = Change directory
- `cd ..` = Move to the parent directory
- `cd .` = Stay in the current directory
- `cd ~` = Move to the user's home directory

## Path Concepts

- `/` = Root directory
- `.` = Current directory
- `..` = Parent directory
- `~` = User's home directory

### Absolute Path

An absolute path starts from `/` and gives the complete location.

Example:

`cd /tmp`

### Relative Path

A relative path starts from the current directory.

Example:

`cd Documents`
