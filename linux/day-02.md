# Day 2: Linux Filesystem

## What I Learned

Today I learned how the Linux filesystem is organized and how Linux uses absolute and relative paths.

## Important Directories

- `/` = Root directory
- `/home` = User home directories
- `/etc` = Configuration files
- `/var` = Logs and changing system data
- `/tmp` = Temporary files
- `/usr` = Programs and libraries
- `/dev` = Device files
- `/boot` = Boot-related files
- `/root` = Root user's home directory

## Path Concepts

- `~` = Home directory
- `.` = Current directory
- `..` = Parent directory

An absolute path starts from the root directory `/`.

A relative path starts from the current directory.

## Commands Practiced

- `find` = Searches for files and directories
- `df -h` = Shows filesystem disk usage
- `du -sh` = Shows disk usage of a file or directory
- `ls -R` = Lists files and directories recursively
- `pwd` = Shows the current working directory
- `cd` = Changes the current directory
