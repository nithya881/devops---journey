## Important Concepts

- pwd displays the current working directory.
- ls lists directory contents.
- cp copies files while keeping the original.
- cp -r copies directories and their contents recursively.
- mv moves or renames files and directories.
- rmdir removes empty directories.
- rm -r removes directories and their contents.
- / is the root of the Linux filesystem.
- /home contains users' personal home directories.
- /etc stores system configuration files.
- /var stores variable data, including system logs.
