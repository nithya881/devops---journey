<h1>Day 1: Linux Basics</h1>

<h2>What I Learned</h2>

<p>Today I learned the basics of Linux and how to work with the terminal.</p>

<h3>Linux</h3>

<p>Linux is an operating system kernel used by many servers and cloud systems.</p>

<h3>Terminal</h3>

<p>The terminal lets me interact with the Linux system by entering commands.</p>

<h3>Shell</h3>

<p>The shell interprets the commands I enter and communicates with the operating system.</p>

<h2>Commands I Learned</h2>

<h3>pwd</h3>

<p>Shows my current working directory.</p>

<p><code>pwd</code></p>

<h3>ls</h3>

<p>Lists files and directories.</p>

<p><code>ls</code></p>
<p><code>ls -l</code></p>
<p><code>ls -la</code></p>

<h3>cd</h3>

<p>Moves between directories.</p>

<p><code>cd directory-name</code></p>
<p><code>cd ..</code></p>
<p><code>cd ~</code></p>

<h3>mkdir</h3>

<p>Creates a directory.</p>

<p><code>mkdir directory-name</code></p>

<h3>touch</h3>

<p>Creates an empty file.</p>

<p><code>touch notes.txt</code></p>

<h3>cp</h3>

<p>Copies a file.</p>

<p><code>cp notes.txt backup.txt</code></p>

<h3>mv</h3>

<p>Moves or renames a file.</p>

<p><code>mv notes.txt linux/</code></p>
<p><code>mv old-name.txt new-name.txt</code></p>

<h3>rm</h3>

<p>Removes a file.</p>

<p><code>rm notes.txt</code></p>

<h3>man</h3>

<p>Shows the manual for a command.</p>

<p><code>man ls</code></p>

<h2>Practice</h2>

<p>I practiced creating directories and files, moving and copying files, renaming files, and deleting files.</p>

<h2>Day 1 Completed</h2>

<p>I completed the basic Linux command-line practice.</p>
